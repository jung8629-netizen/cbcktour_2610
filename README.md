# 종교개혁 투어 도슨트 — 오프라인 웹앱(PWA)

이 폴더 안의 파일을 **GitHub 저장소에 그대로 올리면** 주소가 하나 생기고,
폰에서 그 주소를 열어 "홈 화면에 추가"하면 앱 아이콘이 생기며 오프라인에서도 작동합니다.

## 파일 목록
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (지도·해설·연표·인물·검색) |
| `sw.js` | 오프라인 저장 담당 |
| `manifest.webmanifest` | 앱 이름·아이콘·전체화면 설정 |
| `icon-*.png` | 홈 화면 아이콘 |
| `robots.txt` | 검색엔진 수집 차단 |

⚠️ **폴더째로 올리지 말고, 폴더를 열어 안의 파일들을 올려주세요.**
